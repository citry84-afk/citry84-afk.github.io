Opciones ajustadas = el marcador honesto

Las primas de opciones dicen cuánto genera la máquina, pero las opciones ajustadas descuentan las pérdidas ya realizadas cuando una PUT acaba en asignación y las acciones se venden con pérdida. Por eso esta será la métrica principal de largo plazo.

Criterio: solo descuento asignaciones cerradas con pérdida. Las asignaciones abiertas, como NVO, se vigilan aparte pero no se restan hasta vender.
